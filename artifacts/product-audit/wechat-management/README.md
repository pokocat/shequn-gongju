# 微信管理 - 个人微信列表审查

审查日期：2026-08-17

## 1. 审查范围

- 个人微信的列表浏览和卡片浏览。
- 账号状态筛选、搜索、分页、行级编辑与交接入口。
- 未覆盖导出、新建、编辑、交接和二维码同步的真实服务端流程。

## 2. 证据

- `01-personal-list.png`：个人微信卡片浏览状态。
- `02-personal-list.png`：个人微信列表浏览状态。

## 3. 结论

页面具备账号类型切换、状态筛选、两种浏览方式与基础行操作，核心框架可用；但表格将 19 个字段同列展示，且表头和表体使用独立滚动容器，导致关键运营字段可见性和滚动一致性不足。建议优先改为单一横向滚动容器、冻结账号和操作列，并将 QR、邮箱、证件等低频字段移入详情抽屉或列设置。

## 4. 优先修复项

1. 合并表头和表体的横向滚动容器，避免列错位。
2. 默认显示账号、负责人、项目/地区、好友容量、管理群数、状态、最近同步和操作；其余字段进详情。
3. 点击行后打开右侧账号详情，提供二维码、绑定关系、群位预设、交接记录和编辑入口。
4. 用好友数 `/ 2000`、群数 `/ 20` 与同步异常提示替代无上下文的裸数字。

## 5. 已执行优化

- 默认表收敛为账号、项目/地区、服务负责人、好友容量、管理群位、同步状态、最近同步、二维码和操作九列。
- 表头与表体合并进同一滚动容器；表头在垂直滚动时保持可见。
- 点击列表行或卡片会打开右侧账号详情，集中呈现容量、二维码状态、绑定信息和交接操作。
- 增加城市、好友预警、群容量预警和同步异常筛选；筛选状态和结果数会实时更新。
- 将单页数量提升为 20，避免桌面端在少量数据时出现过大的无效空白。
