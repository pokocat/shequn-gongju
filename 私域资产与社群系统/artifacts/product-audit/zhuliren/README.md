# 主理人公社白底主题验收

日期：2026-08-14

## 验收范围

1. 首页：会员成长、班级社群、课程服务、AI 诊断、公告与底部导航。
2. 我的：会员资料、权益/积分入口、班级关系链、成长任务、账号服务。
3. 社群：我的班级、班群操作、班级成员、班级任务与近期活动。

## 结论

- 三个一级页面统一为白底、黄绿黑色彩，深色霓虹画布不再作为默认主题出现。
- 顶部只保留品牌、PRO 身份和小程序胶囊菜单；状态栏图标改为深色，保证白底可读性。
- 底部保留一个浮动主操作和四个导航入口；面向用户的原型跳转网格默认不渲染，仅 `?prototype=1` 调试时开启。
- 卡片使用白底、浅灰绿边框和低阴影，黄绿色只用于主操作、选中态和成功状态。
- “我的”页移除无业务价值的 A1 装饰图；服务老师头像固定尺寸，避免被内容区域拉伸裁切。
- 社群页的“进入班群”作为单一主操作，添加服务微信为次级操作；切换条、班级信息和任务列表统一为浅色信息层级。

## 可见问题与处理

| 编号 | 问题 | 处理 |
| --- | --- | --- |
| 1 | 外层黑色舞台与白色手机预览冲突 | 预览容器改为浅灰绿背景，顶部系统切换改为白色胶囊导航 |
| 2 | 深色顶部、紫色高光、白色卡片混用 | 通过 `data-ui-theme="lime"` 统一公共外壳、屏幕、卡片、标题和按钮 |
| 3 | 右下角绿色网格属于原型调试控件 | 默认不渲染 `FloatingNav`，保留 `?prototype=1` 开发入口 |
| 4 | “我的”页装饰内容抢占会员资料层级 | 删除 A1 装饰图，压缩资料、任务和设置卡片间距 |
| 5 | 服务老师头像被横向内容布局拉伸 | 固定头像 `34px × 34px`，图片使用 `object-fit: cover` |
| 6 | 社群页仍有紫色操作渐变 | 入群改为黄绿主按钮，服务微信改为白底次按钮，任务图标统一黄绿 |
