# 平台管理页上下文清晰化设计规范

## 背景

平台管理页当前同时受 App 级项目上下文和 `EcosystemManagement` 内部平台上下文影响。页面主体可能显示“主理人公社”平台，但顶部仍显示上一次选择的项目，例如“AI艺人孵化”；进入平台工作台后旧项目值仍然保留。页面中的 SaaS 合作伙伴和平台状态也存在全局信息与当前平台信息混用的问题。

## 目标

- 平台管理页只使用平台上下文。
- 平台管理页隐藏顶部项目切换器。
- 点击“进入平台”后保持平台上下文，不保留旧项目选择。
- 项目只从平台工作台的项目列表进入；进入具体项目后才切换为项目上下文。
- 当前平台的 SaaS 合作伙伴和所属生态从平台记录读取。
- 平台生命周期状态、数据接入状态和营收状态分别展示。
- 不改变现有平台、项目、社群 Scope 的业务模型和非 P0 页面结构。

## 非目标

- 不重做行业生态与平台管理页面的视觉布局。
- 不修改真实后端或接入新的平台数据 API。
- 不处理平台名称变更后的 Scope 迁移。
- 不处理社群 Store 的归档恢复、字段校验等独立遗留问题。
- 不修改移动端或小程序端导航结构。

## 上下文模型

为 `ProjectContext` 增加页面使用的上下文模式，至少支持：

```ts
type WorkspaceContext = "platform" | "project";
```

平台管理页和平台工作台声明为 `platform` 模式。项目工作台声明为 `project` 模式。页面模式由 App/PCLayout 传递，不通过当前项目字符串是否为空推断。

平台模式下：

- 当前平台名称仍可显示；
- 项目选择器不渲染；
- 全局项目值不得影响平台管理主体或平台级社群 Scope；
- 进入平台时清除或隔离旧项目值，避免返回项目页面时误认为仍在该项目中。

项目模式下：

- 显示当前平台和当前项目；
- 项目来自平台工作台项目列表或明确的项目进入动作；
- 项目级社群继续使用 `project:<平台>:<项目>` Scope。

## 组件职责

### `App.tsx`

负责维护平台和项目的全局状态，并向 PC 页面提供上下文模式能力。模块切换到 `ecosystem` 时，平台管理入口使用平台模式；项目进入动作使用项目模式。保持现有平台切换会重置项目的行为，但不让平台管理页依赖项目值显示状态。

### `PCLayout.tsx`

接收当前页面的上下文模式或等价的显示配置。平台模式下隐藏项目选择器，只展示当前平台及页面标题/层级信息；项目模式下保持现有项目选择器行为。视图切换菜单的既有定位、Escape 关闭和外部点击关闭行为不变。

### `EcosystemManagement.tsx`

进入平台时明确触发平台上下文，不复用全局旧项目。平台工作台中的项目列表保留项目进入入口；该入口负责显式切换到项目模式并传递选中的项目。平台级社群入口始终使用平台 Scope。

平台卡片和平台配置抽屉使用同一条当前平台记录，字段语义固定为：

- `status`：平台生命周期状态，例如“运营中”；
- `dataStatus`：数据接入状态，例如“待接入”；
- `revenue`：营收数据状态或金额，例如“待接入”。

SaaS 合作伙伴和所属生态只从当前平台记录读取，不使用无关的全局合作伙伴选择器值。

## 数据流

1. App 根据当前模块确定页面为平台管理模式或项目模式。
2. PCLayout 根据模式决定是否渲染项目选择器。
3. EcosystemManagement 的平台列表点击或“进入平台”按钮只设置当前平台工作台状态，并清理旧项目上下文。
4. 平台工作台项目列表的进入动作显式设置目标项目，页面进入项目模式。
5. 平台级社群组件继续以 `platform:<平台名称>` 读取规则和群库；项目级组件继续以 `project:<平台名称>:<项目名称>` 读取。
6. 平台卡片和抽屉从同一平台对象读取合作伙伴、生态、生命周期状态、数据接入状态和营收状态。

## 错误与边界处理

- 当前平台不存在时，显示已有平台列表的空状态，不读取旧项目上下文。
- 平台模式下即使全局项目值残留，也不得渲染项目选择器或读取项目级社群数据。
- 项目进入动作缺少有效平台或项目时，不切换模式，并保留当前平台管理页面。
- 平台数据缺少 `dataStatus` 时显示“待接入”，不得把 `status` 改写为数据状态。
- 平台工作台返回平台列表时，恢复平台模式并清理项目模式状态。

## 验证标准

### 自动验证

- `npm run build` 通过。
- `npm test -- --run` 通过。
- `git diff --check` 通过。

### 浏览器验证

访问 `?view=pc&module=ecosystem`：

- 顶部显示当前平台，不显示项目切换器；
- 页面主体显示行业生态/平台管理；
- 点击“进入平台”后，顶部仍不显示旧项目；
- 平台工作台显示当前平台项目列表和平台级社群入口；
- 进入具体项目后，项目上下文和项目选择器才出现；
- 平台配置抽屉中的 SaaS 合作伙伴与当前平台一致；
- 平台状态显示“运营中”，数据接入单独显示“待接入”；
- 控制台无新增错误或警告；
- 平台级和项目级社群 Scope 不发生交叉读取。
