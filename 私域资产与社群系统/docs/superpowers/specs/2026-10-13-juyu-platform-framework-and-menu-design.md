# 聚域平台大框架与菜单系统设计（完整规划）

日期：2026-10-13
状态：已确认，实施中
方案：A+B 混合 —— 向导做引导，菜单只有一套骨架
适用范围：聚域 PC 后台（`?view=pc`）

---

## 1. 设计原则

1. **菜单 = 业务流程的状态映射**，不是功能清单。菜单跟随业务操作流程组织：搭建 → 配置 → 运营。
2. **单套骨架 + 向导卡**（本次确认的核心决策）：
   - 菜单永远只有**一套结构**，不存在"配置态菜单/运营态菜单"两套重排；
   - 配置未完成时，菜单顶部多出一张**启动向导卡**（5 步），完成后卡片消失；
   - 卡片消失 ≠ 结构重排，过渡平滑，渲染路径唯一。
3. **配置完成即折叠**：一次性/低频配置项折叠进「系统配置」组，入口保留但不占日常视野。
4. **能力驱动菜单**：订单、渠道、城市、佣金等模块由项目已开通能力决定是否出现。
5. **事件驱动治理**：审批、风控、资产异常通过 badge 提醒，有数字才需要处理。
6. **两个固定例外**：账号资产中心（配置+运营双重属性）、业务能力中心（能力增购是持续行为）始终一级。

---

## 2. 业务操作流程（5 个阶段，已确认）

```text
阶段0  生态搭建（一次性，平台方）
  行业生态/平台管理：建生态 → 建平台 → 平台下挂项目

阶段1  系统账号开通（前置门槛）
  账号资产中心：开通主理人 / 管理员 / 员工系统账号
  → 没有系统账号，能力无法持有和分配

阶段2  能力配置（每个项目一次）
  业务能力中心：用系统账号为项目开通能力
  → 能力决定该项目拥有哪些功能模块

阶段3  业务资产与团队接入（一次性 + 低频维护）
  账号资产中心：个微 / 企微 / 公众号 / 小程序等业务账号
    注册/接入 → 养号 → 分配到项目与员工
  角色与权限：团队权限配置

阶段4  日常运营（每天）
  经营工作台：会员 / 社群 / 项目 / 代理四视角 + 任务闭环
  动态能力菜单：订单 / 渠道 / 城市 / 佣金 / 工单（按已开通能力）
  审批与风控：事件驱动

阶段5  经营分析（周期性）
  数据报表：并入经营工作台，作为分析视图
```

### 2.1 流程关键约束

- **阶段1 是硬前置**：阶段2 的能力开通必须绑定系统账号（持有人、操作人）。
- **账号资产中心在流程中出现两次**（阶段1 系统账号、阶段3 业务资产），因此它既是配置入口又是运营工具，必须固定一级；向导卡 ①②③ 均跳转账号资产中心，落在不同分类 Tab。
- 阶段0-3 全部完成后进入运营态：向导卡消失。

## 3. 系统架构三层模型

```text
┌─ 平台层（固定骨架）
│   行业生态/平台管理 · 业务能力中心 · 账号资产中心 · 角色与权限
│
├─ 能力层（市场与映射）
│   应用（社群增长套件 / 会员运营工作台 / 团长分销 / 城市合伙人）
│   项目小程序（主理人公社 / AI学习社 / …）
│   工具（企微助手）· 方案 · 服务
│   每个能力标注 modules: [会员, 订单, 佣金, 代理, 课程, …]
│
└─ 项目层（能力实例化后的运营空间）
    当前项目已开通能力 → 决定左侧动态菜单 + 工作台数据视角
```

## 4. 菜单系统设计

### 4.1 统一菜单骨架 + 向导卡

菜单只有**一套结构**，任何时期都如下渲染；唯一差异是配置未完成时顶部出现向导卡。

| 状态 | 进入条件 | 菜单表现 |
|---|---|---|
| 配置态 | 向导 5 步未全部完成 | 骨架菜单 + 顶部「启动向导」卡（可最小化，不可关闭） |
| 运营态 | 5 步全部完成 | 骨架菜单，向导卡消失 |

折叠状态持久化（localStorage），跟随项目记忆；用户可随时手动展开折叠组。

### 4.2 菜单结构（最终形态）

```text
⚠ 运营提醒（badge 汇总条，保留现有）

● 启动向导 2/5                        ← 仅在配置态出现，完成后消失
  ✓ ① 开通系统账号      → 账号资产中心·系统账号
  ● ② 开通业务能力      → 业务能力中心（当前项目）
  ○ ③ 接入业务账号      → 账号资产中心·业务资产
  ○ ④ 配置团队权限      → 角色与权限配置
  ○ ⑤ 进入运营
──────────────────────────────
经营
· 经营工作台          固定，默认首页
· 跨项目总览          固定（T5 后并入工作台视图）
· 订单与履约  *       动态，能力 modules 含「订单」
· 渠道与分销  *       动态，能力 modules 含「代理」
· 城市分站    *       动态，能力 modules 含「城市」
· 佣金与结算  *       动态，能力 modules 含「佣金」
· 工单中心    *       动态，能力 modules 含「服务」
· 数据报表中心        固定（T5 后并入工作台视图）
                      （动态项右侧小字标注来源能力）

资产与能力
· 账号资产中心        固定（badge：待交接 + 风控异常数）
· 业务能力中心        固定

治理
· 审批与风控          固定（badge：待审批数）

▸ 系统配置（折叠组，点击展开二级）
  · 行业生态 / 平台管理
  · 角色与权限配置
```

### 4.3 启动向导卡（5 步）

位置：左侧菜单顶部（运营提醒之下）。

```text
项目初始化配置  2/5
① 开通系统账号   ✓ 已完成 → 账号资产中心（系统账号类）
② 开通业务能力   ● 进行中 → 业务能力中心（当前项目）
③ 接入业务账号   ○ → 账号资产中心（个微/企微等业务资产类）
④ 配置团队权限   ○ → 角色与权限配置
⑤ 进入运营       ○ → 全部完成后自动达成
```

步骤完成判定：

| 步骤 | 完成条件 |
|---|---|
| ① 开通系统账号 | 当前项目 ≥1 个管理员系统账号已激活 |
| ② 开通业务能力 | 当前项目 ≥1 个能力状态 = 已开通 |
| ③ 接入业务账号 | ≥1 个业务账号资产（个微/企微/公众号等）已完成分配 |
| ④ 配置团队权限 | ≥1 个角色已配置且绑定员工 |
| ⑤ 进入运营 | ①-④ 全部完成 |

全部完成 → 向导卡消失（首次自动消失，之后尊重用户手动最小化状态）。

### 4.4 动态能力菜单规则

- **显示条件**：当前项目已开通能力中，存在 `modules` 包含对应模块的能力。
- **多项来源**：同一菜单项可由多个能力带来，菜单项右侧小字标注主要来源能力。
- **项目切换**：顶部切换项目时动态菜单即时重算。
- **未开通处理**：未开通的模块菜单项不显示；经营工作台内出现「可开通能力」提示卡，点击跳转业务能力中心。

### 4.5 badge 规则

| 菜单项 | badge 内容 |
|---|---|
| 账号资产中心 | 待交接数 + 风控异常数 |
| 审批与风控 | 待审批数 |
| 工单中心 | 待处理工单数 |
| 订单与履约 | 待履约订单数 |
| 向导卡 / 系统配置组 | 配置态下显示未完成步骤数（如 2/5） |

## 6. 交互细则

1. **默认路由**：进入 PC 后台默认落「经营工作台」。
2. **折叠组行为**：点击「系统配置」展开二级项；二级项选中时组保持展开并高亮父级。
3. **新项目首次进入**：显示向导卡，可最小化不可关闭；完成后自动消失。
4. **URL 同步**：`?module=xxx` 保持现有规则；未开通能力的菜单项通过 URL 直达时，显示「未开通」引导而非报错。
5. **导航栏收起**：侧栏收起时，折叠组降级为图标项，向导卡缩为进度圆点。

### 验收标准

1. 新项目进入为配置态：向导卡 5 步可见，系统配置组可见。
2. 完成 5 步后：向导卡消失，其余菜单结构不变。
3. 项目开通/未开通能力时，动态菜单正确出现/隐藏并带来源标识。
4. 折叠状态刷新后保持。
5. 现有 badge 数字不回归，测试与构建全部通过。
