# 主理人移动端整体打磨设计

## 目标

在不回退现有消息、成长、账户详情和头像替换能力的前提下，完成主理人移动端的视觉一致性、交互反馈和 375px 移动端体验打磨。

## 范围

- 统一主理人公社1头像资源、群头像、状态标签、卡片圆角、间距和安全区表现。
- 为搜索、查看全部、快捷入口、联系客服、账号设置等当前入口提供明确的本地反馈或已有页面跳转。
- 保持五个底部 Tab、消息/项目/成长/账户详情、群试看与升级流程可用。
- 优化固定底部导航、详情返回按钮和主要操作按钮的点击区域与小屏布局。

## 实现方式

继续以 `ZhuLiRenApp.tsx` 作为页面编排入口，复用现有 `ZhuLiRenMessageDetail`、`ZhuLiRenGrowthDetail` 和 `ZhuLiRenAccountDetail` 组件。交互通过现有 React 本地状态和 Toast 反馈完成，不引入后端接口或新依赖。头像继续使用 `/principal-1-h5/assets/avatars` 下的真实静态资源。

## 验收标准

- 375px 宽度下五个 Tab 和主要内容不横向溢出，底部导航不遮挡内容。
- 搜索、查看全部、快捷入口、客服和设置入口点击后均有可识别反馈或进入对应详情。
- 消息已读、项目报名、商品购买、成长任务推进、群升级/入群等既有流程保持可用。
- 所有头像图片加载成功，控制台无新增错误。
- `npm test`、`npm run build`、`git diff --check` 全部通过。

## 风险控制

只修改主理人移动端相关组件和必要的测试/样式使用，不处理其他未关联的工作区变更，不删除用户已有文件，不提交 Git commit。
