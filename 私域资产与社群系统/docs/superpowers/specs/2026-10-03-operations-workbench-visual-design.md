# 运营工作台绿色社区视觉落地设计

## 意图

将已确认的“主理人公社”绿色社区服务视觉直接落地到正式 React PC 工作台，替代独立 HTML 草图作为主要交付入口，同时保持现有会员关系、人工服务、AI 同步、项目工作模式与角色权限逻辑不变。

## 范围

- 调整 `src/app/components/Overview.tsx` 的首页布局、层级、指标卡、关系待办、服务趋势、今日工作清单、AI 同步和运营提醒的视觉表达。
- 调整 `src/app/components/PCLayout.tsx` 的左侧导航、顶部栏、项目上下文、视图切换和整体外壳视觉。
- 仅在必要时调整 `src/app/theme.tsx` 的语义色板，使米白、浅绿、森林绿、柔和边框、圆角与阴影保持一致。
- 不修改 `src/app/components/InfluenceRanking.tsx`；该文件当前有用户或其他工具的有意变更，视觉落地需兼容其现状。

## 视觉方向

- 以米白和浅绿色作为页面底色，以森林绿作为主要品牌色。
- 使用自然、社区服务感的视觉语言，避免霓虹、赛博朋克和高对比技术驾驶舱表达。
- 页面采用分组式左侧导航、清晰的工作台标题、柔和圆角卡片、低对比边框和轻玻璃层次。
- 首页首屏优先呈现“真实连接”：项目会员、待处理关系任务、人工服务完成率、AI 最近同步。
- 关系待办和运营提醒保持可操作性，点击继续通过既有 `onNavigate` 路由跳转。
- 视觉调整必须兼容明暗主题接口，不新增外部依赖。

## 行为与数据约束

- 不改变会员数据来源规则，PC 后台不新增会员。
- 不修改 `personal`、`enterprise`、`group`、`spend`、`ai` 等客观关系字段。
- 人工服务按钮仍只记录人工操作，不将操作结果直接写入客观关系状态。
- 不改变项目关系工作模式和角色权限判断。
- 不把首页演示数据改造成新的业务数据源；真实关系数据接入另行处理。
- 保持用户对 `InfluenceRanking.tsx` 的现有修改，不执行全仓库回滚或无差别 reset。

## 回退边界

实施前记录 `Overview.tsx`、`PCLayout.tsx`、`theme.tsx` 的当前内容或生成局部补丁。若视觉验收不通过，只恢复本次涉及文件，不影响 `InfluenceRanking.tsx` 及其他既有未提交业务变更。

## 验收标准

- 正式 React 页面能在 PC 视图正常渲染，中文文本无乱码。
- 左侧导航、顶部项目上下文、首页主要卡片和操作入口在绿色社区视觉下风格统一。
- 切换项目、角色、工作模式不会改变既有权限和客观关系状态逻辑。
- `yarn build`、`yarn test`、`git diff --check` 通过。
- 浏览器验证 `?view=pc&module=overview`，并检查首页无明显溢出、遮挡或不可点击区域。
