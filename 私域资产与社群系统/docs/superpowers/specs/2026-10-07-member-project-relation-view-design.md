# 会员数据视图与项目关系设计

- 日期：2026-10-07
- 状态：用户已确认设计方向，待进入实施计划
- 范围：会员数据主表视图、项目关系批量运营、会员右侧项目关系档案

## 1. 目标

在会员数据中增加项目关系视图，用于按项目批量筛选和处理会员，同时保留右侧会员档案中的项目关系 Tab，用于单个会员的深度查看和操作。

核心工作流：

```text
会员数据
→ 切换项目关系视图
→ 选择项目与关系状态
→ 找到待处理会员
→ 执行授权、绑定、登录或运营动作
→ 打开会员档案项目关系 Tab 查看完整信息
→ 写入运营记录或任务结果
```

## 2. 信息架构

会员数据提供四种视图：

- 会员视图：会员整体身份、价值、社群、消费和运营阶段；
- 项目关系视图：会员在项目中的授权、账号、登录、绑定、消费和复购；
- 社群关系视图：入群、发言、点击、绑定和社群活跃；
- 订单消费视图：订单、金额、履约、售后和复购。

右侧会员档案保留六个 Tab：

- 会员概览；
- 项目关系；
- 社群关系；
- 订单消费；
- 官方账号；
- 运营记录。

主表视图负责批量运营，右侧档案负责单人详情，不重复承担同一层级的工作。

## 3. 项目关系视图

### 3.1 展示原则

仍然保持一行一个会员，不把一个会员拆成多条项目记录。项目关系通过当前项目筛选和项目摘要展示，避免多项目会员导致主表重复、过宽和难以操作。

### 3.2 筛选条件

项目关系视图至少提供：

- 项目：全部项目或指定项目；
- 关系状态：全部、未授权、已授权未绑定、已绑定未登录、已登录未消费、已消费、已复购、异常；
- 项目运营阶段：待激活、授权中、绑定中、首次登录、待消费、已消费、复购关注、升级机会、维护中；
- 项目身份：项目会员、核心项目会员、项目合伙人、服务人员、代理、体验用户；
- 下一步动作：待授权、待添加账号、待绑定、待登录、待首次消费、待回访、待复购、待升级、无需动作。

### 3.3 字段

默认字段：

- 会员；
- 平台身份；
- 关联项目；
- 当前项目；
- 项目身份；
- 项目授权；
- 项目账号；
- 登录状态；
- 绑定状态；
- 项目消费；
- 项目订单；
- 项目运营阶段；
- 服务人员；
- 下一步动作；
- 操作。

选择具体项目后，当前项目列变为所选项目，其他字段展示该会员在该项目下的关系状态。会员全局身份和项目身份必须分开显示。

### 3.4 顶部指标

项目关系视图顶部展示当前筛选范围的项目漏斗：

- 项目会员数；
- 已授权；
- 已绑定；
- 已消费；
- 已复购；
- 待执行动作。

选择具体项目后，指标只统计该项目，不与会员全局消费指标混用。

## 4. 操作与跳转

列表中的授权、绑定、登录动作继续复用现有账号和关系操作逻辑，不替换原有按钮、状态判断和操作日志。

点击会员名称或查看操作：

- 打开右侧会员档案；
- 默认进入项目关系 Tab；
- 展示该会员的全部项目关系；
- 可继续执行单个会员的授权、绑定和登录引导。

点击下一步动作：

- 打开统一操作台或任务创建流程；
- 自动带入会员、项目、当前关系状态和动作类型；
- 已存在未完成的同对象同动作任务时，定位已有任务，不重复创建。

## 5. 状态与数据边界

项目关系状态按项目维度计算，不使用会员总状态替代。缺少项目配置时显示“待配置”，配置完成但没有样本时显示“暂无数据”，有样本且结果为零时显示真实“0”，不把缺失数据转换为零。

项目消费和订单金额只在选择项目后作为该项目数据展示；会员视图中的累计消费仍然代表会员全局累计值。

## 6. 窄屏策略

桌面端保持横向列表；窄屏保留横向滚动，不强行压缩所有字段。会员和项目关键字段优先可见，下一步动作和操作列必须能够滚动到并执行。右侧档案继续使用全宽抽屉或面板，并保留项目关系 Tab。

## 7. 实施边界

本阶段只调整会员数据视图和项目关系展示、筛选、跳转，不重构任务中心，不修改已有账号添加、入群、关注、状态确认和操作日志能力，不改变其他工作台的数据职责。

## 8. 身份标签与服务关系分配

### 8.1 头像身份标签

会员主表的会员单元格统一展示头像、会员姓名和两类身份标签：平台身份、会员等级。平台身份和会员等级不再单独占用表格列，避免重复展示并释放表格空间给账号、群、消费和运营动作。

### 8.2 服务关系匹配

服务关系使用“平台身份 + 会员等级”的组合规则匹配。匹配结果按当前表单的任务样式展示，并区分会员级和项目级关系：

- 会员级：服务官个微、服务官企微、班主任个微、班主任企微、官方公众号、官方小程序、官方视频号、会员服务群；
- 项目级：项目服务人员、项目服务账号、项目对应群；
- 每个关系保留账号或群名称、当前状态、操作按钮、人工操作次数、操作日志和 AI 同步状态。

当组合规则没有命中时，显示“待分配”，不伪造账号或群；多个匹配结果按当前城市和启用状态筛选，账号和群分别维护独立任务 ID、状态和日志。

### 8.3 表格字段调整

会员视图删除“平台身份”和“会员等级”列，项目关系主表也不重复展示平台身份；项目关系详情继续保留项目身份列。头像标签是会员全局身份的唯一主表展示入口，项目身份只在项目关系场景中展示。

## 9. 验证标准

- 默认会员视图保持现有会员经营字段；
- 会员头像区域同时展示平台身份和会员等级标签；
- 会员视图不再出现平台身份和会员等级独立列；
- 服务官、班主任、个微、企微、公众号、小程序、视频号和对应群按平台身份与会员等级匹配；
- 无匹配关系时显示待分配状态，不展示错误账号或群；
- 服务关系保留状态、按钮、次数、日志和 AI 同步能力；
- 切换项目关系视图后仍然一行一个会员；
- 项目筛选和关系状态筛选可以组合使用；
- 点击会员后进入右侧档案的项目关系 Tab；
- 项目关系视图和右侧项目关系 Tab 的字段口径一致；
- 通过类型检查、测试、构建和差异检查。
