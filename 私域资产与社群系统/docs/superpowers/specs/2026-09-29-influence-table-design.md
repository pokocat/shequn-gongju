# 影响力表格精简设计

## 目标

优化主理人公社小程序影响力详情表格的关系层级文字与本周新增人数展示，使移动端信息更紧凑、易读，且不遮挡单元格中的辅助数据。

## 范围

仅修改 `public/member-app/pages/tasks.html` 中影响力详情表格的展示样式和表格行名称。现有代理端与团长端的指标、列头、数据、权限口径及下钻行为保持不变。

## 关系层级

将行名称统一缩短为两字：

- `我直接发展` 改为 `直推`
- `旗下发展` 改为 `团队`
- `推荐关系` 改为 `推荐`
- 团长端的 `我直接运营` 改为 `直营`
- 团长端的 `我推荐的人` 改为 `推荐`
- 团长端的 `推荐关系发展` 改为 `发展`
- 团长端的 `会员推荐` 改为 `会员`

这些名称仅影响表格显示文本，不改变点击下钻的指标列含义。

## 新增人数

采用用户选定的方案 B：

- 主数字后的 `+N` 使用红色小号加粗文字；
- 不使用红色底框、绝对定位或悬浮徽标；
- `+N` 与主数字保持同一行；
- 下方存在 `潜在 N` 辅助数据时，其单独占行，确保不被新增标记遮挡；
- 表格提示文案对应更新为红色 `+N` 为本周新增人数。

## 验证标准

- 430px 移动端宽度下表格不产生横向溢出；
- 表格行名均为两字且不换行；
- 新增标记与潜在数据没有覆盖或重叠；
- 原有表头、数值和下钻入口仍可用；
- JavaScript 语法检查、差异检查和生产构建均通过。
