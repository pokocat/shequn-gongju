代理 / 团长层级可见范围

先确认“归属、发展、推荐、运营、只读可见”是否需要拆成不同关系。当前图展示推荐方案，不代表已经写入系统。

直属管理 / 自己运营发展关系推荐关系只读聚合不可见

代理本人

默认视角：我运营的社群 + 我发展的网络

代理可见范围

直接运营
我的社群可看成员明细、内容、活跃度、成交服务
发展关系
我发展的代理可看直属资料、状态、经营概览
下属代理发展的团长默认只读：人数、状态、成交贡献
下属团长旗下社群默认聚合：社群数、成员数、成交额
推荐关系
我推荐的人单独标识推荐来源，不与发展代理混为一谈
推荐人发展的团长数据只读聚合，避免越权进入履约和库存

团长可见范围

直接运营
我的社群可看成员明细、内容、跟进、推广转化
推荐关系
我推荐的人可看推荐状态和基础资料
推荐人发展的团长数据仅看数量、状态、贡献等聚合信息
明确不可见
代理库存、发货、售后明细订单只展示路由状态，不展示代理经营后台
非本人推荐链条的社群不进入团长工作台范围
页面建议：代理工作台用“我的社群 / 发展网络 / 推荐网络”三个范围切换；团长工作台用“我的社群 / 我的推荐”两个范围切换。关系标签必须随每条数据显示，避免“团队”一词把直属归属、发展和推荐混在一起。
