# 项目总结与最近变更

## 项目定位

本仓库是蜂乐玛私域社群运营中台的完整设计与前端交互原型。它把账号资产、个人微信/企业微信、微信群、成员入群、客服任务、群分配、会员运营和影响力运营放在同一套 PC 工作台中，并保留早期系统截图、Axure 导出和对比资料，作为产品演进依据。

当前可运行的主应用位于 [`私域资产与社群系统/`](../私域资产与社群系统/)，技术栈为 React、TypeScript、Vite、Tailwind CSS 和 Lucide React。

## 能力范围

### PC 工作台

- 统一侧边导航、模块标题、搜索和页面级操作。
- 账号资产台账：手机号、邮箱、微信、媒体账号、领用关系和状态。
- 微信管理：个人微信和企业微信双模式、状态切换、搜索筛选、列表/卡片视图。
- 企业微信运营字段：绑定个人微信、项目/地区、负责人、成员容量、管理群位、同步状态、最近同步、二维码和交接操作。
- 社群管理：运营列表、状态看板、主从详情、群成员名单、群主状态、容量占用和高频运营动作。
- 客服管理、群分配、影响力排行、会员运营工作台和小程序原型。

### 交互原则

- 个人微信和企业微信共享同一行状态筛选与搜索布局，减少模式切换时的认知成本。
- 列表和卡片视图共享数据、选中项和操作状态；查看、二维码、交接、状态调整等动作在当前上下文完成。
- 详情页中的群状态、容量、成员和运营动作保持同一数据上下文，操作后给出明确反馈。

## 最近变更

以下内容对应当前发布分支最近一轮迭代：

1. 将 PC 后台导航、模块标题和多页面工作台收敛到统一布局。
2. 完善社群管理的三种展示方式：运营列表、状态看板和主从详情，并补充成员名单与群运营动作。
3. 重做微信管理的个人微信/企业微信切换，统一状态栏、搜索栏和浏览方式。
4. 企业微信列表补齐运营所需参数，增加容量进度、同步状态、二维码预览、账号详情和交接表单。
5. 账号资产页增加列表/卡片切换，并将卡片压缩为适合快速扫描的核心字段。
6. 客服、群分配、影响力排行和会员运营工作台继续沿用统一的操作反馈和状态样式。
7. 增加 `public/` 演示资源、`artifacts/` 设计验收资料，以及 `design-qa.md` 记录，便于继续对照预览迭代。

## 本地验证

在主应用目录执行：

```bash
npm run build
```

当前构建可通过，Vite 预览入口为：

```text
http://127.0.0.1:5182/?view=pc&module=wechat
```

## 上传边界

提交到远端的是完整项目源码、配置、必要静态资源、设计资料和历史原型。以下本地生成内容不纳入版本库：

- `node_modules/`
- `dist/`
- `.vite/`
- `coverage/`、`playwright-report/`、`test-results/`
- 各类缓存、Python 字节码、构建日志和 `*.tsbuildinfo`
- `.env` 及其他本地密钥文件（仅保留显式提交的 `.env.example`）

这些规则位于仓库根目录 `.gitignore`，不会影响本地运行，只避免把依赖和编译中间产物上传到 GitHub。
