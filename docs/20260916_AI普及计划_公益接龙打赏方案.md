## 一、机制总览

```
AI 普及计划（7 天社群课，标称价值 1,000 元）
   ├── 报名：公益接龙，0 元参与
   ├── 学习：每日打卡 + 学分
   ├── 打赏：「为 AI 老师充算力」——随心付，0 元起
   │     └── 流向每月公示（算力账单）
   └── 内部：打赏金额 × 接龙行为 → 客户分层雷达
         → 团长按分层跟进 → 转化上车卡/会员/代理
```

**核心设计**：打赏在**对外**是纯自愿公益支持（不挂钩任何商业权益，守住公益性质）；在**对内**是最真实的支付意愿信号——比问卷和口头意向准十倍，且完全合法（属于用户行为分析）。

## 三、玩法机制

### 3.1 公益接龙（报名侧）

- 群内接龙报名：`#AI普及接龙 第 X 位｜昵称｜城市`；
- 接龙自带社交证明：后报名者看到的是一条越来越长的名单；
- 团长专属接龙码（带参数二维码），归因到推荐人。

### 3.2 算力支持话术（打赏侧）

把打赏包装成「给 AI 老师充电」——趣味化 + 化解打赏尴尬：

- 打赏按钮文案：**「为 AI 老师充点电」**；
- 话术 A（开课）：「这堂课，按内容对得起 1,000 元。但公益期一分不收——觉得有用，随心充点电。」
- 话术 B（引导）：「你的打赏不是给我，是给夜校 AI 老师充算力。下一节课能不能继续免费，就看今晚大家充的电。」
- 话术 C（结课）：「本月算力账单已公示，感谢每一位充电的小太阳。」

### 3.3 算力账单（流向公示）

每月公示打赏流向，做成趣味账单（合规公示 + 内容素材一鱼两吃）：

```
【夜校算力账单 · 9月】
本月充电总额：¥23,741
→ 课程制作与讲师：40%
→ AI 算力与工具：30%
→ 掌灯计划公益基金：30%
每一度电，都有去处。
```

### 3.4 荣誉体系（打赏挂钩的唯一回报）

打赏**只挂钩荣誉，不挂钩商业权益**（守住公益性质）：

| 行为 | 荣誉 |
| --- | --- |
| 任意打赏 | 「小太阳」勋章 + 掌灯学分 |
| 打赏 ≥ 100 | 当月「充电榜」公示（自愿晒单） |
| 全勤打卡 | 结业证书 + 天选锦囊参与资格 |
| 团长维度 | 城市「充电榜」荣誉旗 |

## 四、内部机制：打赏分层雷达（核心资产）

### 4.1 客户价值分层（按打赏区间）

| 打赏区间 | 分层 | 判断 | 跟进动作（团长执行） |
| --- | --- | --- | --- |
| 0 元 | 内容型 | 免费习惯，暂无付费意愿 | 学分培育，每周轻触达，等下一期 |
| 1–99 | 认可型 | 有付费意愿，预算敏感 | 邀 9.9 元主题班（押金制），走会员线 |
| 100–499 | 意向型 | 明确认可课程价值 | 直接推上线会员（99/月） |
| 500–999 | 高意向型 | 接近上车卡预算 | 1v1 沟通，推 1,000 元上车卡（7 天体验） |
| ≥ 1,000 | 强意向/强关系 | 付费能力与信任双高 | 天选姐/总部出面：上车卡升级面谈 + Tier C 招商资格预沟通 |

### 4.2 关系强度矩阵（打赏 × 接龙速度 → 判断与推荐人的关系）

| | 打赏高 | 打赏低 |
| --- | --- | --- |
| **接龙快** | 铁粉型（强关系+高价值）→ 团长核心名单，优先发展班长 | 捧场型（关系在、预算浅）→ 维系关系，二期再测 |
| **接龙慢** | 内容认同型（信课程不信人）→ 用内容续钩，弱化人际推荐 | 路人型 → 群发层，不投人力 |

### 4.3 推荐人质量评估（反向赋能团长）

- 每位团长后台可见：自己接龙码带来的报名数、打赏分布、高分层占比；
- 谁推荐的人质量高 → 谁的人脉值得重点经营 → 总部据此辅导与资源倾斜；
- **打赏本身不给代理分账**（公益红线）；代理的收益在后续转化：高分层用户 → 上车卡/会员/代理 → 团长赚合法差价与定额推荐费。

## 五、对外话术纪律（三条铁律）

1. **永远说「随心」，不说「建议多少」**——不设参考价、不暗示金额档次（一旦暗示就是变相定价，公益性质即破）；
2. **打赏与权益脱钩**——不打赏者获得完全相同的课程；打赏者只多荣誉，不多内容；
3. **原价必须真实**——「价值 1,000 元」的前提是 1,000 元上车卡真实在售、内容同源；上车卡下架当天，话术同步撤下。

## 六、团长/代理操作 SOP（一图流）

```
开营前 3 天：朋友圈预热（天选姐白金视觉海报）
开营前 1 天：发接龙码，群内 @所有人 讲规则（0 元 + 随心充电）
D1–D7：每晚发听课链接 + 打卡接龙 + 学分
D3：悄悄标记已打赏名单（后台雷达）→ 对 100+ 者私聊感谢（不提金额）
D7 毕业课：天选锦囊开奖 + 结业证书 + 下一期预告
D8–D14：按分层跟进（0 元层不动 / 1–99 邀主题班 / 100+ 推会员 / 500+ 面谈上车卡）
每月 1 号：转发算力账单（信任续杯）+ 城市充电榜
```
