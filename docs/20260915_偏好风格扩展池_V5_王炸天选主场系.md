## 〇、偏好 DNA 提炼

从圈选词看，你喜欢的名字有四个共性：

1. **人生游戏化**——把人生说成牌局/游戏（王炸、天选、顶配、摘星）；
2. **科技电流感**——把连接说成通电/上线（通电、重连、上线、超导）；
3. **主场主角感**——把社群说成自己的地盘（主场、天选之夜）；
4. **口号行动力**——四字像宣言（掌灯计划、移山计划）。

据此扩六个新风格系，全部保持火土金喜用、不含陈彬、不含水木忌字。

## 八、注册风险特别提示（本轮重点）

你圈选的词多为**通用热词**，单独注册显著性弱，务必组合注册：

| 词 | 风险点 | 建议 |
| --- | --- | --- |
| 王炸 | 牌类游戏通用术语 | 以"王炸社/王炸之夜"整体注册 |
| 天选 | B 站"天选之人"热梗，词本身通用 | 以"天选社/天选之夜"整体注册 |
| 主场 | 体育通用词 | 以"主场社/人生主场"整体注册 |
| 上线 | 通用动词；⚠另有"上线了"建站平台在先（sxl.cn） | 改用"上线社/上线夜校"或换"已读/在线" |
| C位 | 通用热词 | 只作口号/栏目名，不作注册主名 |
| 顶配/超导 | 商品/物理通用词 | 组合注册（顶配社/超导系统） |
| 移山计划 | "移山"三体计划在先出版 | 41/35 类检索后再定 |
| 头号玩家 | 电影名在先 | 已避开 |
| 王牌对王牌 | 综艺名在先 | 已标注改"王牌之约" |

**注册友好度最高的新词**：金乌社、破阵社、出鞘社、天团社、掌门社、充电站（作城市节点名）、王座社、封神台。
