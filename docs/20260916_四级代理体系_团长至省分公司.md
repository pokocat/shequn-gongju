## 一、体系总览（四级 · 修正映射）

| 层级 | 身份名 | 门槛 | 对应既定档位 | 授权范围 |
| --- | --- | --- | --- | --- |
| L1 | **社群团长**（上桌团长） | **1 万** | 团长培训（Tier C） | 授权区县内开班运营；随心付 50% + 课程 30%；可发展预备团长 |
| L2 | **区县代理**（二级） | 3 万 | 社群运营（Tier B） | 区县优先权 + 区县充电站；可发展团长；可卖进阶课 |
| L3 | **市代理**（一级） | 12 万 | 高端共建（Tier A） | 地级市优先 + 天选合伙人身份；可发展区县代理；线下活动主办 |
| L4 | **省市分公司**（= OPC 基地，城市王炸） | 50 万起 | 城市运营中心 | 12 项职能 + 总部势能对接；可推荐市代理；**六项门槛不变** |

**启动通道（既定机制承载）**：1,000 元上车卡（7 天体验、升级全额抵扣）= 预备团长启动位——首批种子团长用上车卡启动开班，30 天跑通后升级 1 万（1,000 全额抵扣），不升级则停止分账授权。

**签约规则（铁律不变）**：所有代理与总部直签；分公司（基地）签《城市运营中心服务合作协议》。

## 四、AI 普惠计划在体系中的位置（随心付口径沿用）

```
省市分公司（基地）—— 城市运营中心：线下场地 + 大项目 + 一日营联办
   │
市代理 —— 市域招商 + 区县代理培训督导
   │
区县代理 —— 区内团长招募与陪跑（服务年卡）+ 自开班拿 50%
   │
团长（1万）—— 普惠班主战场：开班 50% 随心付 + 课程成交 30%
```

**随心付雷达四级化用法**（不变）：团长识人 → 县代识团长（班均认可度）→ 市代看城市充电榜招商 → 总部考核依据（只考服务动作）。

## 六、升级通道与考核

```
预备团长（1,000 上车卡，30 天体验）
  └─ 跑通 1 期班 + 班均认可度达标 → 升级团长（1 万，1,000 抵扣）
团长（1 万）
  └─ 开满 3 期班 + 辖区认可 → 可申请区县代理（3 万，补差价）
区县代理（3 万）
  └─ 辖区团长 ≥5 位 + 服务动作达标 → 可申请市代理（12 万，补差价）
市代理（12 万）
  └─ 履约期满 + 六项门槛 → 可申请省市分公司（OPC 基地，50 万起）
```

**考核只考三样**（不变）：服务动作完成度、学员满意度、合规记录（违规一票否决）。

## 八、合规红线（八条 · 生命线）

1. **结构可以有金字塔，钱不能有金字塔**——按下级业绩抽成出现即熔断；
2. 所有代理与总部直签，收款全走对公，上级不碰下级合同款；
3. 推荐费只算一层定额（500/1,000/2,000，年封顶 2 万）；
4. 服务年卡自愿选购、开服务发票，不与代理资格捆绑；
5. 升级考核只考服务动作，不与下级销售挂钩；
6. 对外话术禁用：躺赚/下级/代理分成/卡位/团队收益/月入 X 万；
7. 随心付三底线沿用：0 元可学完、不设参考价、付款与权益脱钩；
8. 「分公司」在完成工商注册前对外称「城市运营中心」，不构成主体误导。
