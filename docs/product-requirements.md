# 蜂乐玛私域社群运营中台 PRD

## 1. 你要做的系统

你要做的是一套「私域社群运营中台」，不是单纯商城后台，也不是单纯客服系统。

它要把以下业务串成一条闭环：

用户在商城产生交易 -> 用户升级为体验官/尊享官 -> 用户被分配到合适微信号和微信群 -> 客服/服务官持续回访 -> 用户产生复购、推荐和收益 -> 后台统计影响力、转化和社群运营效果。

同时，它还要解决公司和个人在运营过程中大量账号资产难以管理的问题：

手机号 -> 注册微信或平台账号 -> 员工领用 -> 绑定项目 -> 服务不同人群 -> 对应不同微信群。

## 2. 系统解决的问题

### 2.1 账号太多，注册资料和领用关系记不住

问题：
- 公司和个人都有大量手机号、邮箱、微信、媒体账号
- 手机号可能用于注册微信，邮箱可能用于注册公众号、视频号或其他媒体平台
- 账号被谁领用、用于哪个项目、服务哪类人群、对应哪些群，时间一长很难追踪

解决：
- 建立账号资产中心
- 统一记录手机号、邮箱、微信、媒体账号、注册用途、登录资料、领用人、项目、人群和对应微信群
- 保留领用、交接、归还、停用和风险备注

### 2.2 微信号和微信群资产混乱

问题：
- 微信号、二维码、归属客服、地区、微信群、群人数分散管理
- 不知道某个微信号承接了哪些群
- 不知道某个群由谁负责、服务官是谁、群容量是否满

解决：
- 建立微信管理和微信群管理
- 统一维护归属关系、二维码、地区、群类型、入群人数、扫码次数

### 2.3 用户入群和群分配依赖人工

问题：
- 用户该进哪个群靠人工判断
- 用户是否已进群、是否需要换群不清晰
- 群人数满了没有预警

解决：
- 建立群分配模块
- 按地区、身份、推荐人、家族关系、归属客服、群容量自动推荐群
- 支持手动换群和分配日志

### 2.4 客服回访没有闭环

问题：
- 售后、回访、订单问题、入群异常散落在聊天记录里
- 谁处理、何时处理、是否完成不可追踪

解决：
- 建立用户操作台和客服任务
- 从用户档案直接创建任务，设置优先级、提醒时间、处理人、备注和附件

### 2.5 用户关系链和收益不清晰

问题：
- 体验官、尊享官、游客、运营商之间有推荐关系和收益关系
- 但后台没有统一查看直属、间接、家族、影响力和收益

解决：
- 建立用户关系链和收益中心
- 支持影响力排行、直属/间接用户、日报/月报/年报、提现和分销预估

### 2.6 活动触达不可追踪

问题：
- 活动发布、群推送、链接页面、扫码次数、入群转化没有串联

解决：
- 建立活动触达模块
- 支持活动草稿、已发布、富文本、链接页面、推送统计和扫码转化
