## 〇、为什么 W2-5 是「信任承重墙」

随心付从「打赏」定性为「知识服务自主定价」那一刻起，公示义务消失，但**主动公示**反而成了最强的信任广告。

- W2-4 解决了「**7 天学完 0 元**」的承诺兑现问题（学员侧信任）
- W2-5 要解决「**钱去哪了、谁付了多少、团长分了多少**」的透明度问题（公众侧信任）
- 雷达解决「**谁该被推什么、什么时候推、谁来推**」的承接效率问题（运营侧效率）

**一句话**：随心榜对外建信任，雷达对内提效率，两者是 W2-4 普惠班的两条后续承重腿。

## 一、随心榜产品化

### 1.1 三层账单结构

| 层级 | 范围 | 公示渠道 | 频率 | 颗粒度 |
| --- | --- | --- | --- | --- |
| **总榜** | 全网上线夜校所有班级 | 公众号+视频号+小程序首页 | 每月 1 号 | 总额/班级数/学员数/分润总额 |
| **班榜** | 单个班级内部 | 班级群公告+小程序班级页 | 每月 1 号 | 班级总额/参与率/T0-T4 分布 |
| **团长榜** | 团长私域 | 团长朋友圈+私信 | 每月 1 号 | 个人分润/服务分/优秀学员 TOP3 |

> **隐私红线**：所有公示**只显示金额分布与匿名统计**，绝不显示个人姓名+金额的对应关系。学员可查自己的，不可查他人的。T3/T4 大额学员**只在班榜显示「有 X 位大额支持者」**，不显示具体人数以外的信息。

### 1.2 数据模板（JSON，每月 1 号 00:01 由系统生成）

```json
{
  "period": "2026-09",
  "publishAt": "2026-10-01 10:00",
  "global": {
    "totalRevenue": 12860.00,
    "classList": 5,
    "studentCount": 312,
    "payingStudentCount": 87,
    "participationRate": 0.279,
    "avgPay": 147.82,
    "medianPay": 30,
    "topBracket": "100-499",
    "leaderShareTotal": 6430.00,
    "platformShareTotal": 6430.00
  },
  "classes": [
    {
      "classId": "YC-AI-001",
      "className": "上线夜校·AI普及·第1班（一姐）",
      "leader": "一姐",
      "studentCount": 78,
      "payingCount": 24,
      "revenue": 3120.00,
      "distribution": {"T0": 41, "T1": 13, "T2": 8, "T3": 2, "T4": 1},
      "leaderShare": 1560.00
    }
  ],
  "leaders": [
    {
      "leaderId": "L001",
      "leaderName": "一姐",
      "classCount": 1,
      "studentCount": 78,
      "revenue": 3120.00,
      "share": 1560.00,
      "serviceScore": 4.8,
      "topStudents": ["A同学(T3)", "B同学(T4)"]
    }
  ]
}
```

> **字段说明**：
> - `participationRate` = 付费学员数 / 学员总数，每月公示趋势
> - `medianPay` 中位数比平均数更能反映「真实大众意愿」，避免被大额拉高
> - `topBracket` 显示金额区间而非具体数字，防止攀比
> - `serviceScore` 由学员 Day 7 匿名打分（1-5 星），与团长升降级挂钩

### 1.3 账单页设计（HTML 单文件交付）

**文件**：`20260918_随心榜账单页.html`（白金卡片化设计，与方案设计器同款视觉）

**页面结构**：
1. **Hero 区**：当月标题 + 总额大数字 + 参与率徽章
2. **三层切片卡**：总榜 / 班榜 / 团长榜 Tab 切换
3. **金额分布带**：T0-T4 横向条形图（只显示人数占比不显示金额）
4. **班级榜单**：5 班横向对比，按人均支持额排序
5. **团长墙**：5 位团长卡片，头像+服务分+本月分润（隐私脱敏）
6. **信任声明**：三重安全垫（对公收款 / 24h 退款 SLA / 50% 团长分润公示）
7. **下月预告**：10 月新增班级预告 + 招募团长席位

**关键设计原则**：
- 金额区间化显示（9.9 / 30 / 99 / 199 / 500+ 五档），不显示精确数字
- 团长分润**只显示总额不显示比例**（避免被解读为「提成制度」）
- 班级排名**只显示人均档位不显示绝对金额**
- 所有数据下方注明「**自愿、可退、24h SLA**」三件套

### 1.4 公示 SOP（每月 1 号 10:00 准时）

| 时间 | 动作 | 负责人 |
| --- | --- | --- |
| D-1 23:00 | 系统生成上月数据快照 JSON | 系统 |
| D-1 23:30 | 总部复核数据，确认无误后锁定 | 运营 |
| D0 09:00 | 账单页 HTML 渲染完成，存草稿 | 运营 |
| D0 09:30 | 公众号/视频号/小程序首页同步上架 | 渠道 |
| D0 10:00 | **全网公示** + 团长私域分发 | 全员 |
| D0 12:00 | 监控评论区，统一话术回应 | 客服 |
| D0 18:00 | 数据回流驾驶舱，更新看板 | 运营 |

**评论区三件套话术**：
1. 置顶：「为什么我们敢公示？因为 100% 走对公、24h 可退、50% 给团长。这不是营销，是结构。」
2. 高赞模板：「9 月有 X 位学员付了 0 元学完，我们一样欢迎。随心付的意思就是——你觉得值多少就付多少。」
3. 负面应对：「如果你对某笔支付有疑问，24h 内联系客服无条件退款，不需要理由。」

## 二、雷达系统 V1（机制补全）

### 2.1 六层雷达（承接 W2-4 上报表，补全触发逻辑）

| 层 | 触发条件 | 推荐内容 | 推荐人 | 时效 |
| --- | --- | --- | --- | --- |
| **T0** 未看完 | 课程完成 <3 天 | 下期召回名单，**不推荐**任何付费项 | 系统 | 下期开班前 3 天召回 |
| **T1** 学完零付 | 完成 ≥6 天 + 0 付 | 推 9.9 主题班（养信任） | 团长 | Day 8 当晚 |
| **T2** 学完小额 | 随心付 1-99 | 推上线会员 99/月 | 团长 | Day 8 +3 天 |
| **T3** 学完中额 | 随心付 100-499 | **团长 1v1**：推上车卡 1,000 | 团长 | Day 8 +1 天（24h 内） |
| **T4** 学完大额 | 随心付 ≥500 | **报总部，一姐出面**：上车卡+王炸社 Tier 预沟通 | 一姐 | Day 8 当晚（**12h 内**） |
| **T5** 特殊信号 | Day 6 数字人线索 / 主动询问代理 / 朋友圈晒业务 | 单独建档，**招商组直接接手** | 招商组 | 24h 内 |

### 2.2 雷达承接 SOP（24h 闭环）

```
学员 Day 7 提交雷达上报表
        ↓
团长 22:30 前提交总部（W2-4 §5 已定义格式）
        ↓
总部 23:00 派单：
   - T0/T1 → 系统自动召回队列
   - T2 → 团长承接（推会员）
   - T3 → 团长 1v1 承接（推上车卡，话术见 W2-2）
   - T4 → 一姐 12h 内出面
   - T5 → 招商组 24h 内接手
        ↓
承接人 24h 内必须完成首次触达
        ↓
触达结果回流驾驶舱「雷达看板」
        ↓
未触达 / 未成交 自动升级到上一层（团长未成交→一姐，一姐未成交→招商组）
```

### 2.3 雷达看板（驾驶舱新增模块）

**位置**：驾驶舱「数」视图 → 雷达子页

**指标卡**：
- 本月雷达上报班级数 / 总班级数
- T0-T5 各层人数 + 占比
- 24h 触达率（核心 SLA）
- T3+T4 成交转化率
- 一姐出面次数（应 ≤5/月，超出说明团长承接失效）

**预警线**：
- 24h 触达率 <80% → 黄牌
- T3 成交率 <30% → 团长需复盘
- T4 一姐出面 >5 次/月 → 团长承接体系需重构

### 2.4 雷达与随心榜的联动

```
雷达 T3/T4 名单 ──→ 一姐/团长 1v1 承接 ──→ 成交 → 入「下月随心榜·优秀学员故事」（脱敏）
                                ↓
                            未成交 → 入「雷达复盘池」，下月再触达
                                ↓
                            连续 3 月未成交 → 降级为 T1，避免骚扰
```

**关键原则**：
- 雷达数据**只在内部流转**，绝不进入随心榜公示
- 随心榜公示的「优秀学员故事」**必须学员书面授权**，且只讲成长不讲金额
- T4 大额学员**默认不公示**，除非主动要求晒单

## 三、团长赋能包（让团长能独立承接雷达）

### 3.1 团长雷达承接话术包

**T1 推主题班（9.9）**：
> 「同学，看你 7 天全勤完成！下一步推荐《AI 主题班·9.9 元》，3 天专攻一个场景（写文案/做海报/剪视频），跟普惠班一样可以随心付。要不要预留席位？」

**T2 推会员（99/月）**：
> 「同学，你的随心付我们收到了，谢谢支持。作为回礼，推荐你加入上线会员（99/月），每月 4 次直播+专属群+工具包。第一月免费，第二月起随心付。」

**T3 推上车卡（1,000）**：
> 「同学，跟你说个事——你的支持力度告诉我们你是认真想用 AI 做点事的。一姐的上车卡（1,000 元）本月还剩 3 席，包含：12 节实战课+师徒制+项目承接资格。要不要今晚语音聊 15 分钟？」

**T4 报总部（一姐出面）**：
> 一姐私信：「同学，我是上线夜校的一姐。看到你 Day 7 的支持，想亲自跟你说声谢谢。如果你对代理/分公司方向有兴趣，我们约个时间深聊？」

### 3.2 团长避坑指南

| 坑 | 正解 |
| --- | --- |
| T3 直接群发 | **必须 1v1**，群发=把大额线索做成骚扰 |
| T4 团长自己承接 | **必须报总部**，T4 是代理候选，团长无权签代理 |
| 连续触达同一人 ≥3 次 | 第 3 次后**降级 T1**，避免仇恨值 |
| 承接话术提「提成」「分润」 | **绝口不提**，只说「一姐的上车卡」「总部的代理资格」 |
| 24h SLA 拖延 | 系统自动升级到一姐/招商组，团长**失去该线索** |
