## 一、席位进度表 `seat_progress`（市代/团长/县代通用）

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| level | enum | `district_leader`(团长) / `county`(县代) / `city`(市代) / `branch`(分公司) |
| batch_no | int | 批次号（市代 1–6：1折/2折/3折/4折/5折/常价） |
| batch_name | varchar | 如「创始批（1 折）」 |
| unit_price | decimal | 当批单席价 |
| quota_total | int | 批次总席位（市代：500/200/100/100/50/50） |
| quota_filled | int | 已签约数（实时） |
| quota_intent_locked | int | 意向金已锁定本批席位数（1 折优先队列） |
| status | enum | `upcoming`(未开放) / `recruiting`(招募中) / `sold_out`(售罄) |
| opened_at / closed_at | datetime | 批次开闸/售罄时间（涨价触发留痕） |
| city_limit | int | 一城限购数（市代=3；NULL 为不限） |

**触发器规则**：`quota_filled + quota_intent_locked ≥ quota_total` → 本批 `sold_out` → 下一批 `recruiting`（自动+短信通知中控）。

## 二、意向金管理表 `intent_deposit`

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| intent_id | uuid | 意向金单号 |
| user_id / name / phone | — | 缴纳人 |
| amount | decimal | 固定 1,000 |
| paid_at | datetime | **到账时间（1 折排序唯一依据）** |
| target_level | enum | 意向档位（city/district_leader/county） |
| queue_rank | int | 在目标档 1 折队列中的实时排名 |
| status | enum | `active`(有效) / `converted`(已签约抵扣) / `refunded`(已退) |
| expire_at | datetime | 起盘日+30 天 |
| refund_requested_at | datetime | 退款申请时间（SLA：7 个工作日） |
| refund_completed_at | datetime | 退款完成时间 |

## 三、升级账户流水表 `upgrade_account`

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| account_id / user_id | — | 一人一账户 |
| entry_id | uuid | 流水号 |
| amount_in | decimal | 入账金额（意向金/各级合作款/上车卡全部累计） |
| source | enum | `intent_deposit` / `boarding_card` / `district_leader` / `county` / `city` / `branch` |
| deducted_against | varchar | 抵扣指向（如「市代创始批合作款」） |
| balance | decimal | 账户累计可用抵扣余额 |
| created_at | datetime | — |

> 规则：**所有已付款项全额累计抵扣**（1,000→1,000→…一路抵上来）；升级只补差价，退款按规则原路退。

## 六、闸门与控盘触发器表 `gate_control`

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| gate_id | enum | `leader_gate`(团长闸) / `county_gate`(县代闸) / `price_step`(涨价) / `next_wave`(下一波) |
| trigger_rule | varchar | 如 `city_agents_total ≥ 100` / `leaders_total ≥ 2000` / `batch sold_out` |
| current_value | int | 当前值（实时） |
| threshold | int | 阈值 |
| status | enum | `watching`(监控中) / `triggered`(已触发) / `executed`(已执行) |
| executed_at / operator | — | 触发执行留痕（谁开的闸、何时） |

**预设规则（对接 V6 时间表）**：

| 闸门 | 触发条件 | 执行动作 |
| --- | --- | --- |
| 团长闸 | 市代累计 ≥100 人 | 开放团长 1 折通道（1,000 元） |
| 县代闸 | 团长累计 ≥2,000 人 | 开放团长升级县代补差减半 |
| 涨价 | 各批 `sold_out` | 下一批自动开放+公示 |
| 顺延 | 月进度 < 目标（市代 <250 人/月） | **不涨价**，中控加推动作记录 |
| 下一波 | 市代 1,000 席满 | M9 发布会门槛上调 50% 公示 |

## 七、城市/区域表 `region_control`

| 字段 | 类型 | 说明 |

## 八、权限与合规位

| 项 | 设计 |
| --- | --- |
| 看板角色 | 中控（全量）/ 财务（分账退款）/ 市代（仅自家数据）/ 团长（仅自家班级） |
| 数字真实性 | 对外公示页的所有数字（剩余席位/进度）由本系统单源输出——**一处维护，多处展示** |
| 留痕 | 每次涨价、开闸、退款均留 operator + timestamp（应对质疑的审计链） |
| 敏感数据 | 用户身份信息脱敏展示（中控层可见明细） |

## 九、开发优先级建议

| 优先级 | 模块 | 理由 |
| --- | --- | --- |
| P0 | 席位进度表 + 意向金管理 + 收款凭证 | W1–W2 蓄水即用 |
| P0 | 升级账户流水 | 签约当天就要抵扣 |
| P1 | 普惠班运营 + 雷达分层 | M2 团长闸开启后 |
| P1 | 闸门触发器 | M1 中旬市达 100 人前 |
| P2 | 区域表 + 市代侧看板 | M3 后规模化 |
