## 二、逐标检索要点

### ① 万物有言（公益总品牌）

- 检索近似词：万物有言 / 万物有声 / 万物皆言 / 有言；
- 35（广告销售）、16（印刷品·公益物料）、41（教育·讲座活动）；
- 图形标同步：公益锦囊图形 + 「万物有言」书法字；
- 冲突预案：递补掌灯计划 → 千灯计划 → 拾遗计划。

### ② 掌灯计划（公益栏目/志愿者体系）

- 检索近似词：掌灯 / 点灯计划 / 提灯计划（提灯已有教育机构使用，重点排查 41 类）；
- 「计划」两字放弃专用权声明可提高通过率（代理机构会处理）；
- 冲突预案：降级为志愿者体系名，总品牌启用万物回声。

### ③ One&Co CLUB（社群英文商标）

- 检索近似：OneCo / One&Co / One and Co / OneCompany；
- **& 在审查中通常视同 AND**——按 One and Company 组合再查一轮；
- CLUB 为通用词，不因后缀获显著——核心显著部分是 One&Co 整体；
- 同步查域名：oneandco.cn / oneco.club；
- 冲突预案：OPC Planet → OPC Lab（OPCOMM 已列为防御注册）。

### ④ 上线夜校（起盘入口）

- 检索近似：上线夜校 / 上线学堂 / 深夜上线；41 类重点排查「AI 夜校」「夜校」相关在先（2023 年后 AI 课程类申请激增）；
- 9 类（已下载课程/电子出版物）一并布局；
- 冲突预案：AI 普惠营（投放名）→ 追光夜校（若可用）。

### ⑤ 主理人公社（中文主品牌·命门标）

- 检索近似：主理人 / 主理人社 / 主理人社区 / 理人公社——**35 类与 41 类逐一排**；
- 「主理人」在餐饮（咖啡/买手店）、文娱行业在先申请量大，42 类（SaaS 软件）相对空；
- 图形标（朱砂篆印「主理人公社」）与文字标**分开提交**——图形显著性强于文字，即使文字受阻图形仍可注册使用；
- 冲突预案：理人社（35/41/42）→ 有理公社。

### ⑥ 王炸社（招商席位品牌）

- 检索近似：王炸 / 王炸联盟 / 王炸社——35 类重点排（招商加盟服务）；
- 「王炸」若在 35 类被游戏/娱乐在先占据，评估指定服务项目差异（教育培训 vs 游戏开发不同群组）；
- 冲突预案：顶配社（已在命名池）→ 天牌社。

## 三、送检操作流程（本周执行）

1. **官方自检**（免费，当天可做）：中国商标网商标查询系统（sbj.cnipa.gov.cn）→ 商标近似查询 → 逐标逐类输入；
2. **代理机构复核**（付费，3-5 个工作日）：提交六标 + 类别矩阵，出具正式近似检索报告；
3. **占位同步**（不等商标）：账号名全平台占位——主理人公社 / 一姐 / 上线 / 万物有言（视频号/小红书/抖音/公众号/B 站）；
4. **回填定案**：检索结果回《品牌命名定案书》——通过项锁定，冲突项启用备选。

## 五、给代理机构的委托要点（防坑）

- 要求按「文字标 + 图形标 + 英文标」三件套分层报价，拒绝打包模糊报价；
- 明确问：每个标的**近似风险等级**与**建议指定群组**（同一大类下群组不同保护范围不同）；
- 「计划」「CLUB」等通用词缀做放弃专用权声明的必要性与代价；
- 优先级：主理人公社（命门标）> One&Co CLUB > 上线夜校 > 王炸社 > 万物有言 > 掌灯计划。
