## 二、通道对比（企微收款码 vs 小程序）

| 维度 | 企微/微信收款码 | 小程序支付 | 结论 |
| --- | --- | --- | --- |
| 开通门槛 | 低（营业执照即可） | 中（需开发+商户号） | 先收款码过渡 |
| 资金去向 | 商户号→对公 | 同左 | 相同 |
| 分账能力 | 无 | 支持服务商分账 | 量级上来后迁移 |
| 凭证留痕 | 弱（需手动台账） | 强（订单系统自动） | 初期手动台账可接受 |
| **推荐** | **W1-W2 立即启用** | M2 后随系统上线 | 两步走 |

## 三、开票口径

| 收入 | 税目 | 发票品名建议 |
| --- | --- | --- |
| 代理费/意向金 | 现代服务 | 企业管理服务费 / 信息技术服务费 |
| 线上课程 | 现代服务 | 培训费 / 教育信息服务费 |
| 随心付 | 现代服务 | 知识服务费（按实收开票） |
| 项目承接（数字人/数字化） | 现代服务 | 技术开发/技术服务费 |

- 初期按**小规模纳税人**（增值税普票为主，1%/3%）；年应税超 500 万转一般纳税人；
- 经营范围核对：需含「技术服务/技术开发/教育咨询（不含学科类）/广告设计/企业管理咨询」——缺项本周工商变更补齐（费用约几百元）。

## 四、随心付合规要点（三红线）

1. **不叫打赏**：所有物料统一「随心付=知识服务自主定价」，0 元与任意金额权益一致（已在普惠计划 V2 确认）；
2. **分账月结**：团长 50% 初期走**手动月结+分账台账**（对公付款给团长或团长提报个人代开发票），月度对账单双方签认；量级超 50 万/月再上微信服务商分账；
3. **全额进商户号**：随心付款进公司商户号再分出，**禁止**团长个人码收款后上交（资金池风险）。
