## 〇、命盘核验与修正说明

### 出生信息核验

- 出生：1987年3月16日 23:30
- 排盘法：主流子平「子时换日」（23:00 后日柱进位；现代排盘软件默认此法）

| 柱 | 干支 | 核验过程 |
| --- | --- | --- |
| 年柱 | 丁卯 | 1987年立春（2月4日）后 → 丁卯年 ✓ |
| 月柱 | 癸卯 | 3月16日在惊蛰（3月6日）后、清明（4月5日）前 → 卯月；丁年遁月：正月壬寅、二月癸卯 ✓ |
| 日柱 | 乙丑 | 3月16日白日为甲子日；23:30 属晚子时，按换日法进为次日 → 乙丑 ✓ |
| 时柱 | 丙子 | 乙日五鼠遁「乙庚丙作初」→ 子时为丙子 ✓ |

**结论：丁卯 · 癸卯 · 乙丑 · 丙子，正确。**

> 佐证：1949年10月1日为甲子日，距1987年3月16日恰 13,680 天（228 个完整甲子循环），故该日同为甲子日。
> 附注：若依古法「夜子时不换日」，则为甲子日丙子时；主流排盘按换日取乙丑，本方案从主流。
> **修正记录**：旧档案所载「丁卯 癸卯 辛丑 己亥」与该出生时间不符——23:30 已过亥时（21:00–23:00），不可能得出己亥时；且当日为甲子日而非辛丑日。旧命盘作废，V2 初稿据此推导的「辛金日主、喜土金」全部修正为「乙木日主、喜火土」。

### 命局速读

- 日主**乙木**，生于卯月**建禄**，年支再见卯，月干癸水、时支子水贴身相生——身强；
- 天干：丁（食神）· 癸（偏印）· 丙（伤官透时）——食伤双透，调候丙癸俱全；
- 地支：卯卯（比肩禄）· 丑（偏财·金库）· 子（偏印），**子丑六合**，财印相济；
- **格局：建禄格，用丙火伤官泄秀——「木火通明」**。才华外放、口才表达、文教内容之象，与社群、教育、创始人 IP 的事业同构；
- 乙木本象：花草藤蔓，柔韧缠绕、借力向上——生态联盟、借势生长的商业模式与命格同构；
- 日坐丑土偏财＋金库：财星贴身，坐拥财库；
- 2026 丙午流年：火势当值，内容、表达、曝光的大年。

### 命名铁律（V2.1）

1. 不含「陈」「彬」——彬为双木属比劫忌神，双重理由回避；陈字五行属火本不为忌，按既定要求一并回避；
2. 火土优先、金为辅；
3. 忌水忌木——V2 全部水系候选作废；
4. 2–4 字短名，注册与传播双优；
5. 避开纯描述词，不单独用「社群」「公社」「AI」「平台」注册；
6. 创意候选 ≠ 注册结论。
