## 一、女王城堡与新社群的关系（定调：前作叙事 + 资产传承 + 品牌切割）

| 项 | 设计 |
| --- | --- |
| **对外叙事** | 前作与升级版：女王城堡=天选姐运营万人级女性社群的前作；主理人公社=面向所有超级个体的升级之作。招商话术：「陈彬彬做过女王城堡，服务过数万女性创业者——现在她把这套打法升级为主理人公社」 |

> 一句话定调：**女王城堡是前作，主理人公社是续作，王炸社是这一作的招商局。**

## 二、主理人公社适不适合做社群名（结论：适合，且是最自洽的选择）

**适合的四个理由**：

1. **公司名即定位**——招商时「我们的公司就叫主理人公社（杭州）传媒科技有限公司，我们就是做主理人社群的」——名称、主体、业务三位一体，天然可信；
2. **人群精准**——「主理人」正是超级个体/一人公司创始人的当下热词，目标人群自我认领度高；
3. **组织感**——「公社」比「学院」（只教不组织）、比「联盟」（太散）更适合「共同生活、互相成就」的社群形态，且与四级代理的区域组织结构匹配；
4. **历史包袱轻**——相对女王城堡的微商语境，主理人公社是干净的 slate。

**一个必须处理的风险：商标**。

「主理人」是近年高频申请词，「公社」为通用词——组合显著性中等。**企业字号注册成功 ≠ 商标注册成功**（两套系统）。行动：立即检索 35/41/42 类「主理人公社」近似商标；若被占，启用备选（此前命名池已有：**理人社、有理公社、拾理公社、万社计划**），社群对外名用变体、公司名不变（法律主体与对外品牌允许不一致，加副标即可：如「主理人公社 · 理人社」）。

## 三、推荐品牌架构（三层 · 对王炸社的定位调整）

```
公司主体层：主理人公社（杭州）传媒科技有限公司（法律载体，签约/开票/责任主体）
   │
社群母品牌：主理人公社（对外的社群正式名，简称「公社」）
   │         —— 培养超级个体 / 一人公司创始人的组织
   │
   ├── 起盘入口：主理人公社 · 上线夜校（AI 学习社群，7 天 AI 普及课）
   │              「晚上好，我是上线。今晚，你上线。」
   ├── 成长层：AI 创业社（OPC 项目创业人群，看项目→上车）
   ├── 招商品牌：王炸社（城市创始席位 1 折 500 席 · 四级代理 · 已拍板体系不变）
   ├── 公益 IP：掌灯计划（为非遗/老字号/实体发声）
   └── 活动 IP：天选之夜（年度盛典）
人物层：天选姐（创始人 IP）· 上线（AI 创始人/001 号主理人）
```

**王炸社的调整**：从「总品牌」调整为「**招商席位品牌**」——1 折 500 席、四级代理、涨价三铁律这套 B 端叙事全部保留（已拍板不动），但组织归属挂到主理人公社之下。这样分工清晰：**主理人公社收人（组织认同），王炸社收钱（席位成交），上线夜校引流量（AI 学习入口）**。

## 八、英文命名：OPC 拼词方案（创始人问题三的答案）

**确证**：本地知识库多处「OPC 一人公司方法论/OPC 一人公司系统/OPC 一人公司陪跑营」——**OPC = One Person Company** 本就是体系命名原义。

| 层级 | 英文方案 | 说明 |
| --- | --- | --- |
| **社群英文全称** | **One Person Company Commune**（主理人公社） | 与中文直译完全对应；slogan：**One Person, One Company——一个人，一家公司** |
| 体系缩写 | **OPC** | 与 OPC 超级生态天然统一（本来就是一套）；OPC 基地=One Person Company 孵化基地，语义自动升级 |
| 商标注意 | OPC 三字母在 9/35/41/42 类几乎必有大量在先注册 | **OPC 只能作内部体系词/英文描述使用，不可独占注册**——对外商标保护靠中文文字标「主理人公社」+ 图形标（天选印记）+ 英文标 |
| 英文注册备选 | **OPCOMM / OPCommune** | 字母组合显著性高于裸 OPC，检索后可注册为英文商标 |
| 生态英文名联动 | 超导系统=OPC OS · 充电站=OPC Base · 上线夜校=OPC Night School | 全生态一个词根 |

**推荐定案**：中文「主理人公社」+ 英文全称 One Person Company Commune + 体系词 OPC（不可注册、仅作生态统一用语）+ 英文商标备选 OPCOMM（检索后注册）。
