## 〇、方向转向说明

V2.1 的古典系名（明堂社/坤钧社/曦校长）五行对路但**网感不足**——适合挂在营业执照上，不适合被喊出来。V3 转向词根化命名：**选定一个火属性词根，贯穿所有品牌位，形成"命名宇宙"**——传播记忆成本最低、社群黑话自生成。

## 一、网感命名三原则

1. **能开口喊**——名字要能当称呼喊出来（"燃姐来了"比"明堂创始人来了"传播效率高一个量级）；
2. **能造身份词**——社员叫什么比社群叫什么更决定传播（燃友 / 追光者）；
3. **自带一句话**——每个名字配一句能直接发朋友圈的钩子，并支持话题标签（#今晚燃灯 / #追光的人）。

## 六、在先使用提示（正式检索前必看）

- **追光**：追光动画（影视知名）——社群/教育类需检索，影视动画类别避让；
- **光年**：AI 圈曾有"光年之外"（已停运），"光年"为常见词——9/42 类需检索；
- **灯塔**：教育领域在先使用较多；
- **充电**：教育语境常用词，描述性偏强，宜组合注册；
- **燃社 / 焰零 / 焰阵 / 曜零**：造词感强，通过概率相对更高（仍需检索）；
- **超新星**：天文/文娱常见词，检索后启用。
