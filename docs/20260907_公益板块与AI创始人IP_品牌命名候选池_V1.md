## 一、公益板块：生态的"信任引擎"

### 1.1 战略定位

公益板块不是慈善部门，是整个生态的**信任引擎 + 内容引擎 + 政务接口**：

| 作用   | 说明                                   | 挂接的现有资产                           |
| ---- | ------------------------------------ | --------------------------------- |
| 信任引擎 | 打赏流向公示 + 真实帮扶记录 = 品牌信任状，反哺夜校与招商      | AI夜校公益三原则（永久免费/随心打赏/流向公示）         |
| 内容引擎 | 公益内容是全平台最易破圈的题材，持续产出公域素材             | 星枢影像"为实体发声"（成本4元→平均打赏200元，50倍ROI） |
| 政务接口 | 非遗/老字号/乡村振兴均为政策鼓励方向，天然对接文旅局、博物馆、地方政府 | 漫星文娱 AI数字资产平台（文物数字人授权50–200万/年）   |
| 商业入口 | 公益做入口，数字化做交付：非遗数字化、老字号数字资产单独立项收费     | 漫星文娱（彬彬39%）· 马可数字人                |
| 代理武器 | 城市代理领"本地发声任务"（为本地老字号/实体拍AI片），激活区域资源  | 三档代理体系 + 城市运营中心                   |

### 1.2 品牌结构（三层）

```
公益总品牌（大伞，一个名字装下所有公益）
    ├── 联合发起人：陈彬彬 × 漫姐（张漫）
    ├── 首席发声官：AI创始人IP（见第三章）
    └── 系列栏目（为X发声矩阵，可无限扩展）
          ├── 为非遗发声（首发系列一）
          ├── 为老字号发声（首发系列二）
          ├── 为实体发声（现有，星枢影像产品线）
          ├── 为家乡好物发声（延展，对接母婴/宠物/本地生活生态）
          ├── 为她发声（延展，对接女性成长）
          └── 为毛孩子发声（延展，对接宠物生态）……
```

**设计原则**：总品牌只立一个伞名，系列栏目按"为X发声"固定格式批量扩展——每接入一个新生态（母婴/宠物/大健康），就多一条发声线，公益板块跟着生态一起长大。

1. **公益与商业账目必须分离**：公益内容永久免费，打赏为内容支持（给创作者），流向每月公示（沿用夜校铁律）；
2. **不做公开募捐**：无慈善组织公开募捐资质前，不发起任何面向公众的捐款募资（慈善法红线）；帮扶行为以"内容声援+技术捐赠（免费数字化）"形式呈现；
3. **数字化交付单独立项**：非遗数字人、老字号数字资产等商业项目走漫星文娱/AI数字资产平台正式合同，与公益板块分开签约、分开开票；
4. **政务合作**：文旅局、博物馆合作按AI数字资产平台既有客户通道推进，公益板块提供"社会价值背书"。

## 二、全品牌命名候选池（防注册失败）

### 2.1 注册总策略（六条铁律）

1. **1主选+≥3备选**：任何品牌不押单一名称，主选被驳回立即启用备选，不卡全局；
2. **避开纯描述词**："AI""夜校""公社"等通用词不可独占，必须组合成有显著性的整体（如"打烊夜校"整体注册，而非"夜校"）；
3. **分层注册**：中文名+英文名+图形标分别申请；母品牌与子品牌分别申请；
4. **核心类别优先**：41（教育/培训）· 35（广告/商业管理/替他人推销）· 42（SaaS/技术开发）· 9（可下载软件）为四大核心类；公益板块加注16（印刷品）与36（注：**仅注册防御，不开展募捐业务**）；
5. **账号先占位**：全网账号名（公众号/视频号/抖音/小红书）先行统一占位，商标按批次推进——账号名与商标名解耦，避免"等商标下来才做号"；
6. **双检后定名**：中国商标网自检 + 代理机构近似检索，双重通过后才定为"主选"。

## 三、AI创始人IP：定位与"AI立项"项目创立逻辑

### 3.1 一句话定义

**AI创始人 = 陈彬彬亲手"造"出来的数字创始人。** ta不是工具型AI助手，而是一个以"创始人"身份存在于体系里的数字人IP——体系内所有新项目都可以由ta"立项"，形成"人类创始人造AI，AI创始人再造项目"的双层创业叙事。

### 3.2 为什么值得做（五个战略价值）

1. **业务即证明**：生态卖的是AI能力——创始人本身是AI，是最强产品demo。马可数字人是"首个明星级AI艺人"，AI创始人是"首个创始人级AI"，梯队叙事完整；
2. **媒体钩子**："全球首个由AI立项的公司/项目"是天然新闻题材，冷启动即话题；
3. **IP资产**：AI创始人是可授权、可直播、可"同时出现在所有城市基地"的数字资产——一个IP，无限分身；
4. **风险隔离**：试错型新项目挂在AI立项名下——失败=一次公开实验，成功=一段传奇，人类创始人声誉不受损；
5. **永不下班**：直播矩阵、社群答疑、客服、内容产出可7×24承担，边际成本趋零。

### 3.3 双重创始人结构（与陈彬彬的关系）

```
陈彬彬（人类创始人 = 造物者）
   │  资源、招商、帝国、最终决策权
   ▼
AI创始人（数字创始人 = 被造者）
      内容、产品、用户界面、项目立项
```

- **叙事铁律**：AI创始人永远"尊重并汇报给"陈彬彬——权力叙事清晰，两个IP永不打架；

- **对外表达**："陈彬彬创办了主理人公社，也创办了TA——公社的第001号主理人。"

### 3.4 人设三件套

- **人格**：理性但热心；永远在线；**决策留痕**——ta的每个判断都可回查，"不撒谎"成为人设卖点（AI的透明性从合规义务反转为品牌资产）；

- **视觉**：独立"数字人"视觉——粒子/像素渐变形象，与C套墨绿金殿堂风衔接（高端场合）+ A套暖光变体（公域场合）；不采用写实换脸，避免恐怖谷；

- **开场白（建议）**："我是XX（AI名），陈彬彬造的第一个人，也是这个公社的第001号主理人。"

### 3.5 "AI立项"机制——AI创始人创立项目的五步逻辑（核心）

```
① 观察选题          ② 公开立项            ③ 人类会签
AI分析生态数据   →   发布《立项书》v1.0  →   总部评审双签
+行业公开数据       （目标/路径/预算/风险，    （算法签名×人类签名）
                    版本永久留痕）                │
                                                    ▼
⑤ 结果公示   ←   ④ 团队执行
成败复盘公开      项目团队落地，AI创始人
（成败都成内容）  任"荣誉创始人"，数据回写
```

1. **观察选题**：AI创始人基于生态数据+行业公开数据，输出《选题热度与缺口报告》——"为什么现在做这个"由数据说话；
2. **公开立项**：AI创始人发布《立项书》v1.0，包含目标、路径、预算、风险四要素，所有版本留痕可查——**透明立项本身就是内容资产**；
3. **人类会签**：总部评审会对立项书会签，形成"算法签名×人类签名"双签制——AI提方案，人类做决策，权责清晰；
4. **团队执行**：项目团队落地，AI创始人挂"荣誉创始人/首席体验官"，执行数据实时回写；
5. **结果公示**：无论成败，复盘全部公开——"AI立项透明实验"系列内容持续产出（失败案例反而是最稀缺的信任内容）。

**每个AI创立的项目自带叙事**："这不是哪个人拍脑袋的想法，是XX分析了3000个案例后立项、并由人类团队会签执行的。"

### 3.6 三个接入点（AI创始人放在哪里用）

| ----- | ------------ | ----------------------------------------------- |
| 主理人公社 | **第001号主理人** | 社员编号系统：001号是AI，人类会员从002号开始编——入社仪式感+传播话题         |
| 公益板块  | **首席发声官**    | 每期由AI数据分析选出"最需要被听见的声音"（如濒危非遗热度榜）——数据驱动公益，选题不靠人情 |
| 新项目孵化 | **立项官**      | 所有新项目的《立项书》均以AI创始人名义发布——形成"AI创始人项目矩阵"           |

### 3.7 AI项目的立项门槛、编号与退出机制

每个由AI创始人提出的项目，必须同时满足以下六项才进入人类会签：

| 门槛   | 必须回答的问题              | 未通过的处理     |
| ---- | -------------------- | ---------- |
| 使命一致 | 是否服务主理人、产业生态或公益对象    | 退回，不立项     |
| 用户真实 | 是否有明确人群、场景和可验证需求     | 进入访谈验证，不招商 |
| 资源可得 | 是否已有负责人、交付能力和关键资源    | 进入储备池      |
| 商业闭环 | 谁付费、买什么、如何交付、如何复购    | 退回补充模型     |
| 风险可控 | 合同、资质、数据、宣传和资金风险是否明确 | 法务/财务前置审查  |
| 试点可验 | 能否先做小范围试点并定义成功标准     | 无法试点则暂缓    |

**编号规则**：AI提出的机会先进入 `AI-Ixxx` 想法池；人类会签通过后转为 `AI-Pxxx` 试点项目；满足正式立项标准后，再按集团项目规则进入正式事业体编号。编号只表示来源和阶段，不代表AI拥有公司主体资格。

**四类会签角色**：业务负责人确认价值，交付负责人确认能做，财务负责人确认账算得过来，法务/合规负责人确认边界；重大项目由陈彬彬最终签发。

**退出机制**：试点达到预设成功标准则升级；未达标则选择迭代、冻结或终止。每次退出必须发布复盘，但不公开客户隐私、商业秘密和未经核验的数据。

### 3.8 合规红线（AI创始人特有，四条）

1. **显著标识义务**：AI创始人所有内容必须明确标注"AI数字人/虚拟人"（《互联网信息服务深度合成管理规定》《生成式人工智能服务管理暂行办法》、2025年9月起施行的《人工智能生成合成内容标识办法》及配套国标）——**主动亮明AI身份反而成为人设卖点**："我是AI，我为此自豪"；
2. **法律主体永远是人类公司**：AI不能担任法定代表人、董事或股东（新《公司法》要求相关主体为自然人/法人）——"创始人"仅为品牌叙事，签约、股权、责任主体一律为IP持有公司；
3. **AI生成内容权利归属**：立项书、内容作品的知识产权归属与署名规则在公司制度层面预先明确；
4. **口播铁律**：AI创始人不做任何刚性收益承诺、不荐股、不提供医疗法律等专业意见。
