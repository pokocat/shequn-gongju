## 第一条 合作性质与内容

1.1 甲方授权乙方在约定区域内开展「王炸社」体系内的代理合作，具体授权范围、权益与限制见**附一《分档权益表》**。

1.2 本协议为**商业合作合同**，双方为独立民事主体，不构成劳动、合伙、雇佣或特许经营关系；乙方不得以甲方名义对外从事本协议外的任何行为。

1.3 各档位授权范围（概要）：

| 档位 | 席位价（常价） | 核心授权 |
| --- | --- | --- |
| 社群团长 | 1 万 | 开班运营、随心付一级分账、课程分销 |
| 区县代理 | 3 万 | 区县独家授权、发展团长、团长陪跑 |
| 市代理 | 12 万 | 地级市授权（一城 3 席）、发展区县代理、线下活动主办 |
| 省市分公司 | 50 万 | 城市运营中心（另行签署《城市运营中心服务合作协议》） |

1.4 **卡位期条款**：乙方以 1–3 折档位签约的，享有卡位期权益（开班授权+一级分账+区域意向锁定 6 个月）；**区域独家授权与发展下级代理权**自乙方补差至当期 4 折及以上价格档后激活。

## 第二条 价格、付款与升级账户

2.1 合作价款：¥【 】（按签约当期公示价格档执行，详见价格公示页）。

2.2 乙方已支付的意向金/上车卡款项**全额抵扣**本条价款；该等款项连同本协议价款一并计入乙方**升级账户**，乙方后续升级更高档位时按累计已付金额抵扣、仅补差价。

2.3 付款方式：对公转账至甲方指定账户；甲方依约开票（服务类）。

2.4 **涨价锁**：乙方签约后，甲方后续任何价格调整不影响乙方已获权益；升级时按「乙方已付累计金额 → 目标档当期价格」补差执行。

## 第三条 区域规则

3.1 市代理档位实行一城限 3 席；区县代理一区一位。区域席位的分配以签约付款时间为准。

3.2 意向锁定：卡位期区域意向优先权 6 个月，自签约日起算；期满未补差激活正式授权的，区域释放，甲方可另行授权。

3.3 乙方跨区域经营需经甲方书面同意；未经同意的跨区域推广、招揽行为视为违约。

## 第四条 分账与结算（核心条款）

4.1 乙方收入构成及结算规则：

| 收入线 | 规则 | 结算 |
| --- | --- | --- |
| 普惠班随心付款 | 开班团长得 **50%** | 按月 |
| 课程/会员成交 | 乙方专属码成交的 **30%** | 按月 |
| 进阶课/实战营 | 20%（县代及以上 25%） | 按月 |
| 线下产品 | 按主办/联营协议另行约定 | 单独结算 |
| 推荐费 | 推荐团长 **500**/人、县代 **1,000**/人、市代 **2,000**/人（**仅一层**，年封顶 20,000） | 按月 |
| 服务产品 | 乙方作为卖方销售陪跑年卡（见 4.3） | 按月 |

4.2 **团队计酬红线**：乙方不得以任何形式从其推荐的下级代理的业绩、销售额中抽成、返利；所有代理与甲方直签，款项全部经甲方对公账户结算。违反本条的，甲方有权立即解除协议并取消全部未结分账。

4.3 服务年卡（自愿购买）：乙方可自愿购买/销售甲方体系内的陪跑服务年卡（团长陪跑年卡 1,980/年、区县陪跑年卡 5,000/年、市代运营体系年卡 20,000/年）。**服务年卡不构成任何档位代理资格的前提条件，不与授权捆绑。**

4.4 甲方保证价格公示页、结算系统数据的真实、准确；乙方可随时查询本人相关数据。

## 第五条 双方权利义务

5.1 甲方义务：提供课程体系、AI 答疑工具、开班 SOP、话术库与培训支持；按第四条及时足额结算；公示价格、名额、区域规则并真实执行。

5.2 乙方义务：依法合规经营；按甲方统一规范开展社群运营（含「0 元可学完、不设参考价、付款与权益脱锅」的随心付三底线）；如实向学员传达产品信息；妥善处理学员投诉。

5.3 乙方对外宣传不得使用「卡位、躺赚、下级、代理分成、团队收益、月入 X 万、保证回本」等表述；不得以甲方名义承诺任何收益。

## 第六条 冷静期与退出

6.1 签署后 **3 个自然日内**，乙方可无条件书面通知甲方解除本协议，甲方在扣除已实际发生的服务成本（如有）后退还剩余价款（意向金抵扣部分同步处理）。

6.2 冷静期外退出的：已消耗权益（已开班分账、已发放物料与服务）按实际发生结算，剩余部分双方协商退还方案；区域授权同步释放。

6.3 甲方违约（价格/名额/结算不实、未按约结算）的，乙方有权解除协议，甲方退还相应未消耗价款并承担违约责任。

## 第七条 数据与隐私

7.1 双方就合作中获取的学员信息、经营数据负保密义务；乙方遵守个人信息保护相关法律法规。

7.2 甲方对平台运营数据享有所有权；乙方对其私域用户关系在合规范围内的运营权受本协议保护。

## 第八条 协议期限

8.1 有效期【1】年，期满前 30 日双方无异议则自动续期一年；任一方可于期满前 30 日书面通知不再续期。

## 第九条 违约责任与争议解决

9.1 任何一方违约给对方造成损失的，应承担赔偿责任。

9.2 本协议适用中华人民共和国法律；争议协商不成的，提交甲方所在地有管辖权的人民法院。

## 第十条 其他

10.1 本协议自双方签署（含电子签）且价款到账之日起生效。

10.2 附件与本协议具有同等效力：附一《分档权益表》、附二《随心付三底线与宣传合规清单》、价格公示页（签约当期版本存档）。

10.3 本协议一式两份，双方各执一份。

## 附二《随心付三底线与宣传合规清单》

1. 0 元可学完：不付款也能完成 7 天全部课程；
2. 不设参考价：不得向学员明示或暗示「建议付多少」；
3. 付款与权益脱钩：付款金额与课程权益完全无关，付款者仅获荣誉性认可；
4. 禁用词：卡位/躺赚/下级/代理分成/团队收益/月入 X 万/保证回本/稳赚；
5. AI 生成内容标识：AI 老师相关物料须标注「AI 数字人」。
