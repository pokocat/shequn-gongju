```
  │    ③规则全部公示，你可以截图监督。」
  ├─「等等再说」→ 「席位按到账排序，1 折 500 席卖完即止。
  │    你等的不是时间，是涨价后的 2 折。」
  └─成交 → 对公/收款码 + 凭证截图 + 意向金协议电子签
```
