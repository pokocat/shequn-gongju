# 蜂乐玛私域社群运营系统

这是一个面向运营、客服、服务官和管理层的私域社群运营中台原型仓库。仓库同时保留早期截图/Axure 离线原型，以及当前持续迭代的 React/Vite 主系统，方便对比、追溯和继续设计。

## 当前主系统

主系统位于 [`私域资产与社群系统/`](./私域资产与社群系统/)，入口和运行方式见该目录的 [README](./私域资产与社群系统/README.md)。本地预览地址：

```text
http://127.0.0.1:5182/?view=pc&module=wechat
```

```bash
cd 私域资产与社群系统
npm install
npm run dev -- --host 127.0.0.1 --port 5182
```

生产构建：

```bash
npm run build
```

## 会员小程序页面总览

会员端（微信小程序）的全部页面导出成了静态 HTML，放在
[`会员小程序页面导出/`](./会员小程序页面导出/)，双击其中的 `index.html` 即可浏览，
不需要微信开发者工具。共 41 个页面 / 147 屏（同一页面的不同状态各算一屏），
画布 430 × 932，与设计稿同尺寸。

**不是重画的效果图**：由小程序仓库 `apps/member-app/miniprogram` 的真实 WXML / WXSS
渲染而来，`rpx` 已按 430/750 换算回设计稿原始 px，量到的数就是画稿上的数。
文字与数字是演示数据。详见该目录的 [README](./会员小程序页面导出/README.md)。

## 项目内容

- PC 私域后台：账号资产、微信/企业微信、社群、群分配、客服、影响力和运营工作台
- 个人微信与企业微信：统一状态栏、搜索筛选、列表/卡片浏览、容量和同步状态、二维码和交接交互
- 社群管理：运营列表、状态看板、主从详情、成员名单、群状态和容量操作
- 账号资产：手机号、邮箱、微信和媒体账号的台账与紧凑卡片浏览
- 历史原型：`蜂乐玛.zip` 整理出的 PC 后台、小程序和 Axure 资料
- 会员小程序：主理人公社会员端 41 个页面的静态导出，见上文
